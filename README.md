# 대전 지역화폐 결제 패턴 분석 앱 (개선 버전)

## 변경 사항
- 상권 전체 매출/폐업 위험 예측으로 혼동되는 표현 제거
- 지역화폐 결제 저점기 지표로 명칭 변경 (정책 인과관계 주장 제거)
- 동별 점유율의 분모를 필터 적용 전 수집된 전체 지역화폐 결제액 기준으로 통일
- 분석 불가능한 행정동/6개월 미만 자료에 대한 안내
- 최근 추세 예측의 오차 20%라는 미검증 문구 제거
- 대전 평균 종합점수 50점 고정값을 실제 계산으로 교체
- 상대위험 순위의 동점 처리 개선
- 분석 대상 지역 수 동적 표시
- 선택 지역 월별 자료 CSV 다운로드 기능 추가
- 현재 연도를 기준으로 분석 기간 슬라이더 자동 갱신

## 배포
1. 기존 GitHub 리포지토리의 app.py를 이 파일로 교체합니다.
2. requirements.txt 파일을 함께 업로드합니다.
3. 기존 Streamlit Community Cloud 설정의 SERVICE_KEY Secret은 그대로 둡니다.
4. 지도가 필요하면 기존 dong_coords.csv 파일을 같은 폴더에 유지합니다. 이 파일은 제공받지 않았으므로 ZIP에는 포함되지 않습니다.

## 주의
- 업로드된 requirements.txt에는 라이브러리 버전 고정이 없습니다.
- 실제 API 키/실시간 응답과 지도 좌표 파일을 제공받지 않아 라이브 서비스 구동 검증은 하지 않았습니다.
- 종합 리스크 점수는 탐색적 상대 지표이며 검증된 위험 확률이 아닙니다.
- 예측 부분은 선형 추세 시나리오이며 정확도 검증을 거친 예측 모델이 아닙니다.
